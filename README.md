Part 1. Getting Started with jQuery:

Task 0. Setup: Included jQuery via CDN, implemented the $(document).ready() wrapper function, and verified setup by printing "jQuery is ready!" in the browser console.

Task 1. Selectors & CSS: Created a professional profile section displaying name, headline, and introduction. Utilized tag, ID, and class selectors, dynamically updated content using .text() and .html(), applied styles via .css(), and implemented light/dark theme switching buttons.

Part 2. jQuery Effects:

Task 2. Visibility Methods: Built an "About Me" section with a short biography, status message, and fun facts, utilizing Hide, Show, and Toggle buttons to control their visibility.

Task 3. Fade Methods: Integrated gallery images and controlled their visibility smoothly using .fadeIn(), .fadeOut(), and .fadeToggle() effect methods.

Task 4. Slide Methods: Designed interactive collapsible accordion panels with clickable headings and global slide controls, leveraging .slideUp(), .slideDown(), and .slideToggle().

Part 3. DOM Manipulation with jQuery:

Task 5. Add & Remove Elements: Implemented a technical skills list with text input, .append(), .prepend(), and .remove() methods, including input validation to prevent empty skill entries.

Task 6. Modifying Attributes: Added a dynamic social media link and a toggle button utilizing .attr() to switch between different profile links.

Task 7. Form Interaction: Created a contact form with Name and Email inputs that display user typing in real-time below the form using .val() and .text().

Part 4. Animations:

Task 8. Basic Animation: Added visual skill proficiency bars and implemented an "Animate My Skills" button using jQuery's .animate() method to dynamically adjust and reset bar widths.

Work Process Summary:
In this project, I developed an interactive portfolio web application utilizing HTML5 structures, CSS3 styling, and jQuery. I began by setting up the jQuery environment and utilizing precise selectors and CSS manipulations. Next, I incorporated core jQuery features including visibility toggles, fade effects, and smooth slide accordions. I then applied advanced DOM manipulation techniques for dynamic list modifications, attribute switching, and real-time form input previews. Finally, I implemented custom UI animations for skill bars using .animate(). After verifying all functionalities and ensuring error-free execution across all components, I organized the files and published the project.
